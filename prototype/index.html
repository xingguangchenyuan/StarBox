v2 相对 v1 改了什么

  • 侧栏改成两段。上半是一组导航：全部游戏 / 最近游玩 / 正在运行 / 收藏，紧接着四个分类（动作 / 角色扮演 / 独立 / 模拟），中间不再有「分类」小标题和分割线——分类是筛选的一部分，不是另一块区域。
  • 下半是完整游戏列表，占满剩余高度，自己滚动。它就是 Steam 游戏库那种列：小封面、名字、时长，还在跑的游戏带一个绿点。按哪个，右边就是哪个游戏。
  • 点游戏＝进入启动与详情页。不再有独立的「详情页」跳转，右区在库视图和游戏视图之间切换，左上角「返回游戏库」回去。
  • 四个页签接上了实际内容。概览 / 成就 / MOD / 启动选项，成就和 MOD 的筛选与开关都能点。
  • 启动按钮与运行态联动。点「开始游戏」变「切回游戏」，旁边出现结束按钮；退出后写回最近游玩。
  • 列表与封面墙解耦。侧栏列表始终是全量游戏（只被搜索影响）；封面墙才受导航、分类、平台筛选控制。
原型为纯 HTML/CSS/JS 静态稿，仅用于确认布局、层级与交互，不是产品代码。
数据写死在 app.html 顶部，接 Tauri 后由 SQLite 与 Steam 接口提供；真实封面、截图、成就图标届时替换。
